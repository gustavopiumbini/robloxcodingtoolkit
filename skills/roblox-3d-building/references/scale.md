# Scale reference (studs; 1 stud ≈ 0.28 m)

| Thing | Size |
|---|---|
| R15 avatar | ~5.5 tall, ~2 wide (shoulders), ~1 deep |
| Door | 4 wide × 7.5 tall (double door 7-8 wide); frame 0.4 |
| Window | 3-5 wide × 4 tall, sill at 3 |
| Floor-to-ceiling | 12-14 (house), 16-20 (shop/hall), 24+ (castle hall) |
| Wall thickness | 1 (interior 0.6-1, castle 3-4) |
| Stairs | rise 1, run 1.5-2, width ≥ 5; landings every ~12 steps |
| Railing | 3.5 tall, posts every 4-6 |
| Corridor | ≥ 6 wide (8 for multiplayer traffic) |
| Table / counter | 3 / 3.5 tall; chair seat 2 |
| Bed | 4 × 7 × 2 |
| Car | ~7 wide × 16 long × 5 tall |
| Tree | trunk Ø 1.5-3, 18-35 tall; canopy 12-20 wide |
| Street lamp | 12-14 tall |
| Road lane | 12-14 wide; sidewalk 6-8 |

Movement (defaults WalkSpeed 16, JumpPower 50 ≈ 7.2 studs jump height):
- Max comfortable obby gap ≈ 10 studs horizontal on flat ground; max ledge ≈ 6.
- Humanoids step up ≤ ~2 studs without jumping; use 1-stud steps.
- Leave ≥ 8 studs clear around spawns.
